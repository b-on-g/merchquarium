# PRD: Каталог мерча

## 1. Цель

Простой онлайн-каталог мерча художницы: коврики для мыши, пеналы, игрушка-кисточник и другие изделия . Покупатель смотрит товары и одной кнопкой начинает диалог в Telegram. Владельцы (автор и её муж) сами добавляют, правят и убирают товары прямо в каталоге, без отдельной админ-панели и без помощи разработчика.

Первая версия решает одну задачу: показать товары и перевести заинтересованного человека в личный диалог. Оплаты, корзины и учёта в версии 1 нет.

## 2. Пользователи и роли

- **Посетитель** (без входа): видит каталог, фильтрует по категориям, нажимает на карточку == нажимает «Купить».
- **Админ** (вход через аккаунт Гипер Базы): всё то же, плюс редактирование каталога.
  редактирование прямо на странице каталога, у админка карточка которая не видна посетителю с "+" посередине. отдельного окна редактирования нет, редактировать и менять можно просто по клику на поле\ях карточки
- возможны другие авторы со своими каталогами.

## 3. Технические рамки

- Стек: $mol / MAM, данные в Гипер Базе.
- Хостинг: GitHub Pages (статика, бесплатно).
- Сначала только стандартные компоненты $mol и функциональность. Оформление (красивый дизайн) будет отдельным этапом после того, как всё работает.

## 4. Данные

**Товар** ( ему соотвестует компонент карточка = "card" )

- название (текст)
- цена (число, рубли)
- описание (текст)
- фотографии (несколько, порядок важен, первая является обложкой)
- категория (одна из списка, например «коврики», «пеналы»)
- в наличии (да/нет)

**Категория:** название. Список категорий строится из тех, что указаны у товаров

## 5. Функциональные требования

### 5.1 Каталог 

- Главная страница показывает сетку карточек товаров. Карточка: все поля, для админа редактируются по клику и кнопка купить
- Над сеткой табы/фильтр по категориям. Есть вариант «Все».
- 

### 5.2 Кнопка «Купить»

- Открывает Telegram-диалог с владелицей с готовым текстом: «Добрый день, хотел бы приобрести X», где X это название товара.
- Реализация: ссылка вида `https://t.me/<ник>?text=<текст, закодированный для URL>`.
- Для товара «нет в наличии» кнопка неактивна.

### 5.3 Статус «нет в наличии»

- Такая же карточка, но неактивная (нельзя купить), поверх неё специальное изображение «товара нет» (картинку предоставляет автор).
- Админ переключает статус на карточке

### 5.4 Режим админа

Все элементы редактирования видны **только админу**. Посетитель их не видит и не может вызвать.

- **Добавление:** в конце сетки стоит специальная карточка с большим «+» вместо товара. Нажатие  создает пустую карточку 
- **Редактирование:** админ может изменить у любого товара цену, фото, описание, название, категорию и статус наличия.
- **Удаление:** специальная кнопка на карточке товара (видна только админу). Удаление требует подтверждения.
- Вход: через аккаунт Гипер Базы .

## 6. Критерии приёмки версии 1

1. Посетитель без входа видит каталог и может отфильтровать товары по категории.
2. Нажатие «Купить» открывает Telegram с корректным текстом и названием товара.
3. Товар «нет в наличии» отображается неактивной карточкой со специальным изображением, купить его нельзя.
4. Админ после входа видит карточку «+», кнопки редактирования и удаления; без входа их нет.
5. Админ может добавить товар с несколькими фото, изменить его и удалить.
6. Изменения админа видны посетителям после обновления страницы, данные сохраняются между сессиями.
7. Приложение собирается и публикуется на GitHub Pages.
